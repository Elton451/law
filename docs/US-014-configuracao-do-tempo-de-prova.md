# US-014 — Configuração do tempo de prova

**Persona:** Estudante
**Prioridade:** Média

## História
Como estudante, quero ajustar o tempo-limite dos casos concretos, para treinar no ritmo que preciso.

## Critérios de aceite
- [ ] As configurações (no menu) têm a opção "Tempo de prova".
- [ ] O tempo pode ser definido entre 30 min e 1h30, com intervalos de 15 min.
- [ ] O valor padrão é 1h.
- [ ] O sistema exibe a dica: "Sugerimos no máximo 1h para treinar a velocidade de produção."
- [ ] A configuração vale para os próximos casos concretos iniciados.

## Dependências
- US-017.
