# US-016 — Estudo: como fazer as peças

**Persona:** Estudante
**Prioridade:** Alta

## História
Como estudante, quero ler resumos sobre como identificar e redigir cada peça processual da matéria, para saber estruturá-las na prova.

## Critérios de aceite
- [ ] O sistema lista as peças cadastradas para a matéria (ex.: petição inicial, contestação, apelação).
- [ ] Cada peça tem um resumo escrito pelo admin, explicando como identificá-la no caso concreto e como estruturá-la (endereçamento, qualificação, fundamentação, pedidos, fechamento).
- [ ] A leitura segue o mesmo padrão visual dos resumos das trilhas (US-008).
- [ ] Ler o conteúdo de uma peça concede XP na primeira vez.

## Dependências
- US-015, US-025.
