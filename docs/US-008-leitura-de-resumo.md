# US-008 — Leitura de resumo

**Persona:** Estudante
**Prioridade:** Alta

## História
Como estudante, quero ler os resumos de uma lição, para aprender o conteúdo teórico antes de praticar.

## Critérios de aceite
- [ ] O resumo é exibido com a formatação definida pelo admin (títulos, listas, negrito, citações de artigos de lei).
- [ ] A leitura é confortável no mobile (tipografia e espaçamento adequados).
- [ ] Ao final do resumo, o estudante marca como lido (ou o sistema marca ao chegar ao fim).
- [ ] Marcar um resumo como lido concede XP (US-011) e conta para o streak (US-012).
- [ ] Ao terminar, o sistema sugere o próximo conteúdo da lição (ex.: os flashcards).
- [ ] O estudante pode reler resumos já concluídos sem perder o status.

## Regras de negócio
- O XP de um resumo é concedido apenas na primeira leitura.

## Dependências
- US-007, US-022.
