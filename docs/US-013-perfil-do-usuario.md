# US-013 — Perfil do usuário

**Persona:** Estudante
**Prioridade:** Média

## História
Como estudante, quero ver e editar meus dados e acompanhar minhas estatísticas, para gerenciar minha conta e meu progresso.

## Critérios de aceite
- [ ] O perfil exibe nome, e-mail e data de cadastro.
- [ ] O estudante pode editar o nome e alterar a senha (informando a senha atual).
- [ ] O perfil exibe XP total, streak atual, maior streak, progresso por trilha e quantidade de casos concretos realizados.
- [ ] O perfil dá acesso ao histórico de casos concretos (US-020).

## Fora de escopo
- Avatar ou gato personalizável.
- Alteração de e-mail.

## Dependências
- US-011, US-012.
