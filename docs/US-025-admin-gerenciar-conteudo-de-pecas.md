# US-025 — Admin: gerenciar conteúdo "Como fazer as peças"

**Persona:** Administrador
**Prioridade:** Alta

## História
Como administrador, quero cadastrar resumos sobre cada peça processual por matéria, para alimentar a área de Estudo do estudo de caso.

## Critérios de aceite
- [ ] O admin cria, edita e exclui peças vinculadas a uma trilha (nome da peça e ordem).
- [ ] Cada peça tem um resumo com o mesmo editor da US-022.
- [ ] O conteúdo é publicado imediatamente.

## Dependências
- US-004.
