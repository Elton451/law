# US-022 — Admin: gerenciar resumos

**Persona:** Administrador
**Prioridade:** Alta

## História
Como administrador, quero escrever e editar resumos dentro das lições, para disponibilizar o conteúdo teórico aos estudantes.

## Critérios de aceite
- [ ] O admin cria, edita e exclui resumos vinculados a uma lição.
- [ ] O editor suporta formatação rica: títulos, negrito, itálico, listas, citações e links (editor WYSIWYG ou Markdown).
- [ ] O admin visualiza o resumo como o estudante verá antes de salvar (preview).
- [ ] A lição pode ter mais de um resumo, em uma ordem definida.
- [ ] O conteúdo é publicado imediatamente ao salvar.
